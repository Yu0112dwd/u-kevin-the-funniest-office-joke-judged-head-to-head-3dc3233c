## The joke

> Our standup ran so long the intern aged out of the internship, got promoted, and retired — still waiting for his turn to speak.

One line, 127 characters — a standup meeting so long it outlasts a whole career.

## How it works

`main.ts` (Node 22, standard library only, no network) writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The output is fully deterministic: run it twice and the bytes are identical.

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
